# Vision-Speech-Motion-Security-Robot

An autonomous security robot developed using the EZ-Robot JD Humanoid platform to detect human presence and motion, provide spoken alerts, and respond to voice commands.

— Tools & technologies used: EZ-Robot JD Humanoid, EZ-Builder, EZ-Script, JavaScript, Camera Tracking, EZ-Speech, Voice Recognition
— Developed a multimodal security robot that continuously scans its surroundings using servo-based movements, detects faces and motion through its camera, and provides appropriate voice alerts such as “Human Detected” and “Motion Detected.” The robot also supports voice commands for movement, scanning, turning, and stopping, enabling autonomous and remote security monitoring.
